Build a smart mock test app for CBSE school students (Class 6–10) who are learning foreign languages like French, German, and Spanish.
The app should be friendly, colorful, and easy to use for school students.

🎯 App Objective

The app should help students practice and improve their language skills through AI-generated interactive questions. It should work like a personal language tutor that:

Lets the student select:

Class (6–10)

Language (French / German / Spanish)

Chapter or topic (based on syllabus)

Difficulty level (Easy / Medium / Hard)

Generates mock test-style questions in that language.

Accepts typed answers from the student.

The AI agent evaluates the response and gives:

Score or feedback

Correction or suggestion in simple English

Encouraging message like “Nice try!” or “You’re improving fast!”

🧠 Agent Behavior

The AI agent should understand the student’s level from class and difficulty selection.

It should adapt the next question based on performance (if a student answers well, make the next one slightly tougher).

Use a friendly personality like a virtual teacher — polite, encouraging, and fun.

Responses should feel conversational, not robotic.

📱 UI & UX Design

Clean, mobile and tablet-friendly layout.

Top bar: App name “LangBuddy”

Home screen: Cute animated icons for each language.

Once the student selects language → show chapter list → then start test.

Question area: Card style container with rounded corners and soft shadows.

Student answer box: Big text area + Submit button.

Feedback area: Smooth fade-in animation for AI response.

Option to “Try Next Question” or “End Test”.

Keep colors bright and school-friendly (soft blue, yellow, white).

Include a simple progress tracker (e.g., 3/10 questions done).

🔧 Core Features

Language & class-based question generation.

Real-time feedback using AI agent responses.

Progress tracking (session-based, no login required at beta stage).

Reset option to start new test.

Simple leaderboard (local storage only) showing best score per session.

🚀 Beta Version Goals

Focus on 3 languages: French, German, Spanish.

Limited to Classes 6–10 (CBSE) syllabus structure.

No login system yet.

Save test data locally for session only.

Use modular structure so future updates (like voice input or grammar tips) can be added easily.
